## 公式与引用

公式
- 单元格内容以等号=开头
- 保留计算步骤

引用：另一个单元格的值
- 类型
  - 相对引用：=L3
  - 绝对引用：=$L$3
    - 锁行列
  - 混合引用：=$L3、=L$3
    - 只锁行或列
- 可以跨工作簿，又称为链接
  - 默认，绝对引用，可以改

## 统计函数

- countif
- countifs
- sumif
- sumifs

### countif

- 条件计数
- 参数，哪个区域、什么条件

```excel
countif(区域, 条件)
```
```excel
countif(F:F, >300)
countif(E:E, H8)       ## H8的值
```

### countif

- 多条件计数

```excel
countifs(区域1, 条件1, 区域2, 条件2, ...)
```
```excel
countifs(D:D,I5, E:E,J5)
```

### sumif

- 条件求和
- 参数，区域、条件、求和区域（可选）

```excel
sumif(条件区域, 条件[, 求和区域])
```
```excel
sumif(F:F, >300)
sumif(E:E, H8, F:F)
```

### sumifs

- 多条件求和

```excel
sumifs(求和区域, 条件区域, 条件, 条件区域2, 条件2, ...)
```
```excel
sumifs(F:F, D:D,I5, E:E,J5)
```

## IF的使用和嵌套

```excel

```
```excel

if(B2>=5000, round(B2/3, 2), 200)
```

## vlookup

- 查找引用类函数
- 找谁、在哪里找、引用谁

```excel
vlookup(找的值, 查找区域, 引用的列（相对于查找区域的第几列）, 是否精确匹配)
```
```excel
vlookup(L10, A:D, 4, 0)
```

注意
- 一定要锁定查找区域，选择整列、或绝对引用

小技巧
- 添加$（绝对引用），选中区域，按F4

跨表
- 点击fx，及时点击不同参数，可以切换表

## vlookup 进阶

### 模糊查找

- 查找值使用星号（*）连接

```excel
vlookup("*"&L10&"*"*, A:D, 4, 0)
```

### 近似匹配、模糊匹配

- 查找区域，数值升序排列
- 返回靠近的值

```excel
vlookup(E3, $L$7:$M$13, 2, 1)
```
- 可用于工资税率表

等效的函数 lookup

```excel
lookup(查找的值, 查找区域, 返回值所在列)
```

## 日期本质论

excle 中的日期就是数字

函数
- day()：提取日期中的天数
- month()：提取日期中的月份
- year()：提取日期中的年份

其他函数（周）
- weekday()：返回当周第几天
  - 参数，日期、返回周天的类型
- weeknum()：返回当年第几周
  - 参数，日期、一周开始的星期

其他函数（工作日）
- networkdays()：返回两个日期之间的完整工作日数
  - 参数，起始日期、结束日期、假期
- workday()：返回在指定若干个工作日之前/之后的日期
  - 参数，起始日期、天数、假期

datedif
- 隐藏函数

```excel
datedif(开始日期, 结束日期, 类型值)
```

|类型值|说明（计算结果是两个日期间隔的）|
|:-|:-|
| y| 年数|
| m| 月份数|
| d| 天数|
| ym| 月份数，不考虑年数|
| yd| 天数，不考虑年数|
| md| 天数，不考虑年数、月份数|
