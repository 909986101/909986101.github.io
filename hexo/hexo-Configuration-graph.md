# hexo 配置之图表

## mermaid

> https://github.com/webappdevelp/hexo-filter-mermaid-diagrams

**安装模块**

```bash
$ npm install hexo-filter-mermaid-diagrams --save
```

**主题 _config.yml**

```yaml
# Mermaid tag
mermaid:
  enable: true
  # Available themes: default | dark | forest | neutral
  theme: forest
```
